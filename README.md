# IELTS Words

雅思词汇练习网站，提供双栏查词、英汉配对和逐字拼写。每个词在每个主题下有配对、拼写两颗星，进度保存在浏览器本地。

词头由提供的扫描版 PDF 的索引识别而来，按书中 22 个主题分组。OCR 仍可能存在误读或遗漏。词义补充来自 [ECDICT](https://github.com/skywind3000/ECDICT)，见 [MIT 许可证](ECDICT-LICENSE.txt)。带来源标注的例句来自 [Tatoeba](https://tatoeba.org/)，许可为 [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/)，每条例句链接至原文及署名。

可直接打开 index.html，也可使用 GitHub Pages 从 main 分支根目录部署。
