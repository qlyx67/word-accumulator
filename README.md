# 单词累积器 · Word Accumulator

解压后打开网页目录中的 index.html 即可试用。正式部署时，请通过固定网址访问，以便浏览器能识别同一个网站的进度。

- 「查词」会在输入英文单词或短语后查询释义、音标和例句。站内词典数据来自 ECDICT，经 Wordlists 整理。例句及录音可能需要联网，录音不可用时尝试设备语音。查询结果可直接加入学习。
- 「浏览词库」可筛选已掌握、未掌握和有错题记录的词。
- 配对与拼写可按主题或分组出题，另有仅未练习、仅错词和错词混合模式。仅未练习按当前玩法判断，打开题目但没有作答不会记为已练。
- 错词本汇集两种玩法的历史错词。错词本的快捷按钮沿用当前主题和分组。
- 一个词的配对星与拼写星都点亮，才计为已掌握。

## 存档与进度

Git 分支 archive/ielts-baseline 保存开发起点，main 保存单词累积器。基础词表来自 IELTS Words 的校对版（上游提交 4ccbb08ecee1b22088d0012ffa31b3eea78dddc3）。词条沿用该版本的校对范围。

星星、作答记录和错词写入当前浏览器的 localStorage。网页没有登录和云同步，与原雅思站的进度分开。换设备、浏览器、浏览器档案或站点来源（协议、主机名、端口）会看到独立进度。清除网站数据、卸载浏览器或结束无痕会话可能清除原进度。用同一浏览器档案访问同一固定网址可继续练习，进度还没有应用内导出功能。

释义与例句来源见网页页脚。ECDICT 的许可见 ECDICT-LICENSE.txt。
